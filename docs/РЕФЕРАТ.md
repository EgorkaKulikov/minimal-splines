# Реферат программы для ЭВМ

Материалы к заявке на государственную регистрацию программы для ЭВМ.

## Название программы

minimal-splines — библиотека квадратичных минимальных сплайнов и квазиинтерполяции для платформы JVM.

## Реферат

Программа представляет собой библиотеку для платформы JVM, реализующую построение квадратичных минимальных
сплайнов по произвольной порождающей системе и приближение функций квазиинтерполянтами с локальными
аппроксимационными функционалами. Область применения — численные методы, в которых требуется локальное
приближение функций сплайнами класса C¹ с точным воспроизведением заданного трёхмерного пространства функций:
интерполяция и сглаживание данных, дискретизация операторных уравнений, построение базисов для методов
коллокации и проекционных методов.

Существующие библиотеки сплайнов (SciPy, Hipparchus, Apache Commons Math) реализуют только полиномиальные
сплайны и не допускают порождающих систем с иными компонентами, точно воспроизводящих, например,
гиперболические или тригонометрические функции. Интерполяционные сплайны этих библиотек строятся решением
глобальной системы линейных алгебраических уравнений (СЛАУ) по всем узлам сетки, так что каждый коэффициент
зависит от значений функции на всём отрезке.

Программа обеспечивает следующие функциональные возможности: задание сеток с кратными краевыми узлами
(равномерных, квазиравномерных, геометрических, градуированных); задание порождающей системы φ = (1, ρ, σ) —
полиномиальной, гиперболической, тригонометрической или пользовательской; построение базиса минимальных сплайнов
по аппроксимационному соотношению и вычисление сплайна с производными до второго порядка; пять семейств
аппроксимационных функционалов (проекционные, де Бура–Фикса трёх порядков, дискретные де Бура–Фикса,
усредняющие, трёхточечные) и построение квазиинтерполянта по ним; проверку невырожденности сетки и порождающей
системы; вычисление погрешности приближения на контрольной сетке.

Отличительные особенности программы состоят в следующем. Сплайны строятся по произвольной порождающей
системе с невырожденным вронскианом и точно воспроизводят пространство span{1, ρ, σ}; для полиномиальной
системы они совпадают с квадратичными B-сплайнами. Коэффициенты квазиинтерполянта вычисляются локальными
функционалами, зависящими от функции только на носителе базисной функции, без решения глобальной СЛАУ; два
семейства функционалов биортогональны базису и задают проекторы на пространство сплайнов. Все величины
порождающей системы вычисляются в локальных координатах сеточного интервала, благодаря чему число
обусловленности обращаемых матриц не зависит от числа интервалов, положения и масштаба отрезка, а вырожденность
контролируется явным порогом с возбуждением исключения. Линейная алгебра выполняется через библиотеку
numerical-core единой реализацией BLAS/LAPACK — системной либо переносимой на Java, с одинаковым поведением
проверок и исключений.

## Тип ЭВМ

IBM PC-совместимые, Apple Silicon и иные, поддерживаемые виртуальной машиной Java версии 21.

## Язык программирования

Kotlin 2.0.

## Операционная система

Linux, macOS, Windows с установленной виртуальной машиной Java версии 21 или новее.

## Объём программы

Около 90 КБ исходного кода (1417 строк в 6 файлах на языке Kotlin, каталог `src/main`). Размер
скомпилированного артефакта `minimal-splines-1.0.0.jar` — 57 КБ.

## Год создания

2026.

## Зависимости

- виртуальная машина Java версии 21 или новее;
- numerical-core 1.0.0 (`io.github.egorkakulikov:numerical-core`, лицензия Apache License 2.0) —
  линейная алгебра и квадратура; через неё — netlib 3.2.0 (`dev.ludovic.netlib`, лицензия MIT), слой
  доступа к BLAS/LAPACK с переносимой реализацией на Java.

Сборка выполняется средствами Gradle 8.9 и Kotlin 2.0.0.
