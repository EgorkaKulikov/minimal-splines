# minimal-splines

Библиотека квадратичных минимальных сплайнов и квазиинтерполяции для платформы JVM. Сплайны строятся по порождающей
системе φ = (1, ρ, σ): полиномиальной (1, t, t²), гиперболической (1, sinh t, cosh t), тригонометрической (1, sin t, cos t)
или заданной пользователем. Базис ω_j определяется аппроксимационным соотношением Σ_j a_j ω_j(t) = φ(t); каждая функция
ω_j имеет носитель из трёх соседних интервалов сетки, базис образует разбиение единицы и точно воспроизводит span φ.

Приближение функции g строится квазиинтерполянтом P_χ g = Σ_j χ_j(g) ω_j с локальными аппроксимационными функционалами
χ_j. Реализованы пять семейств: проекционные θ, функционалы де Бура–Фикса ξ^⟨r⟩, их дискретные аналоги ξ̃, усредняющие μ
и трёхточечные λ. Каждый коэффициент χ_j(g) зависит от g только на носителе [x_j, x_{j+3}]; семейства θ и ξ
биортогональны базису и потому задают проекторы на пространство сплайнов.

## Обоснование

Распространённые библиотеки сплайнов реализуют только полиномиальный случай. SciPy (`interpolate.BSpline`, `make_lsq_spline`),
Hipparchus (`PolynomialSplineFunction`, `SplineInterpolator`) и Apache Commons Math строят кусочно-полиномиальные функции;
порождающие системы с иными ρ и σ, точно воспроизводящие гиперболические или тригонометрические функции, в них не
представлены. Для системы (1, t, t²) минимальные сплайны совпадают с квадратичными B-сплайнами, и библиотека
воспроизводит их с точностью округления.

Интерполяционные сплайны этих библиотек требуют решения глобальной системы линейных алгебраических уравнений (СЛАУ) по
всем узлам сетки. Квазиинтерполяция локальными функционалами обходится без неё: коэффициент при ω_j вычисляется по
значениям g (для семейства ξ — и её производной) в нескольких точках носителя, поэтому изменение g на одном интервале
влияет лишь на соседние коэффициенты, а порядок сходимости O(h³) на гладких функциях сохраняется.

Методы построения базиса и функционалов взяты из работ Ю. К. Демьяновича по минимальным сплайнам и из работ А. А. Макарова
и Е. К. Куликова; перечень источников с привязкой к элементам кода приведён в `docs/ИСТОЧНИКИ.md`.

## Подключение

Требуется JDK 21 или новее. Зависимость `io.github.egorkakulikov:minimal-splines:1.0.1` публикуется в GitHub Packages;
линейная алгебра выполняется библиотекой `io.github.egorkakulikov:numerical-core`, которая подключается транзитивно из
собственного репозитория. Для чтения обоих репозиториев требуется токен с правом `read:packages` (`gpr.user` и `gpr.token`
в `~/.gradle/gradle.properties` либо переменные окружения):

```kotlin
maven {
    url = uri("https://maven.pkg.github.com/EgorkaKulikov/minimal-splines")
    credentials {
        username = providers.gradleProperty("gpr.user").orNull ?: System.getenv("GITHUB_ACTOR")
        password = providers.gradleProperty("gpr.token").orNull ?: System.getenv("GITHUB_TOKEN")
    }
}
maven {
    url = uri("https://maven.pkg.github.com/EgorkaKulikov/numerical-core")
    credentials {
        username = providers.gradleProperty("gpr.user").orNull ?: System.getenv("GITHUB_ACTOR")
        password = providers.gradleProperty("gpr.token").orNull ?: System.getenv("GITHUB_TOKEN")
    }
}
```
