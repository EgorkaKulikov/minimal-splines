# standalone-consumer — контракт стороннего потребителя

Отдельная Gradle-сборка, которая подключает `numerical-core` и `minimal-splines` как
опубликованные Maven-артефакты и реализует численный метод, не связанный с интегральными
уравнениями: квазиинтерполяцию `f(t) = exp(sin 3t)` минимальными сплайнами с семействами
`theta` и `mu`, таблицу `E_h` с порядками сходимости и численное дифференцирование через
`omegaDeriv`. Импортируются только пакеты `numerics.*` и `splines.*`.

Это исполняемая фиксация архитектурного контракта: будущий независимый («четвёртый»)
репозиторий должен собираться против двух библиотек **без** `integral-equations`. Если для
компиляции этого примера понадобится что-либо из решателей — границы разделены неверно.

Запуск из корня `minimal-splines` (обе библиотеки предварительно опубликованы в
`~/.m2` командой `./gradlew publishToMavenLocal` в каждом репозитории):

```bash
../../gradlew -p examples/standalone-consumer run
```

Ожидаемый результат: порядки `p_h` около 3 для обеих таблиц (квадратичные сплайны) и
около 2 для производной.
